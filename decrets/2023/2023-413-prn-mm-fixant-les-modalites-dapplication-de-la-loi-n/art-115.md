# Article 115

Les prestations spécifiques pouvant faire l’objet de sous‐traitance dans le cadre des activités minières, sont notamment :
les travaux de développement ;
la réalisation de sondages ;
l’abattage de minerai ;
le tir à l’explosif ;
le chargement de produits issus de l’abattage de minerai ;
le transport de produits ;
le soutènement ;
le remblayage ;
l’exhaure ;
le roulage ;
la réalisation de travaux de recherche dans un site d’exploitation ;
la réalisation partielle ou totale des travaux préparatoires d’une exploitation minière ;
la réalisation des travaux de fermeture des mines.
