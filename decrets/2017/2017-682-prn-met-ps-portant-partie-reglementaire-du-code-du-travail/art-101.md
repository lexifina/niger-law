# Article 101

L’apprentissage par alternance est un mode de formation ayant pour but, l’acquisition d’une qualification professionnelle initiale reconnue, permettant l’exercice d’un métier dans divers secteurs d’activités liées à la production de biens ou de services.
L’apprentissage par alternance met en relation les acteurs suivants :
le centre de formation ;
l’entreprise ou l’atelier ;
l’apprenti.
