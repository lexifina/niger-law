# Article 143

Sont saisis, détruits ou dénaturés les crustacés présentant les défauts, altérations et maladies suivants :
aspect terne, sale, vieux ;
enduit poisseux ;
odeur forte ammoniacale ;
moisissures ;
putréfactions diverses ;
relâchement musculaire notable ;
mycoses diverses ;
peste ;
parasitoses (bopyre, sacculine).
