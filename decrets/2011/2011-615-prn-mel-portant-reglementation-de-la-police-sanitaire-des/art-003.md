# Article 3

Catégorie des maladies communes à plusieurs espèces.
Sont inscrites dans cette catégorie, les maladies suivantes :
Fièvre charbonneuse ;
maladie d’Aujeszky ;
échinococcose/Hydatidose ;
cowdriose ;
leptospirose ;
fièvre Q ;
rage ;
paratuberculose ;
myiase à Cochliomyia hominivorax ;
myiase chrysomya bezziana ;
trichinellose ;
fièvre aphteuse ;
stomatite vésiculeuse ;
fièvre catarrhale du mouton ;
fièvre de la Vallée du rift ;
trypanosomose ;
fièvre West Nile ;
babésioses ;
gale.
