# Article 9

Catégorie des maladies des oiseaux Sont inscrites dans cette catégorie, les maladies suivantes :
bronchite infectieuse aviaire ;
laryngotrachéite infectieuse aviaire ;
tuberculose aviaire ;
hépatite virale du canard ;
entérite virale du canard ;
choléra aviaire ;
variole aviaire ;
typhose-Pullorose aviaire ;
bursite infectieuse (maladie de Gumgoro) ;
maladie de Marek ;
mycoplasmose aviaire (Mycoplasma gallisepticum) ;
chlamydiose aviaire ;
influenza aviaire hautement pathogène ;
maladie de Newcastle ;
coccidioses aviaires.
