# Article 21

Le décret ou l'arrêté qui accorde le bénéfice du code des investissements fixe notamment :
l'objet, l'étendue, le lieu d'implantation et la durée de réalisation du programme d'investissement :
les avantages accordés aux bénéficiaires et leur durée ;
les obligations auxquelles l'entreprise est assujettie.
