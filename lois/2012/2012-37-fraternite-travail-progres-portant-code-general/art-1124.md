# Article 1124

Le détournement des objets saisis est assimilé à un vol s’il est commis par un tiers désigné gardien, et est, à ce titre, puni par l’article 307 du Code pénal. Il est assimilé à un abus de confiance s’il est réalisé par le contribuable saisi constitué luimême gardien et puni à ce titre par l’article 338 du Code pénal. Dans le cas où il est amené à constater la disparition du bien saisi, l’agent de poursuite dresse un procès-verbal qui permet de faire constater le délit par le Parquet. Le détournement d’objets saisis constitue un délit même si la saisie était nulle pour vice de forme.
