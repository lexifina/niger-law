# Article 562

Sont désignés sous le nom de machines à timbrer, les appareils destinés à apposer sur les documents ci-après énumérés, 1es empreintes représentatives de divers droits de timbre perçus par les Recettes des Impôts, dont ces documents sont passibles. L’emploi de machines à timbrer est autorisé pour le timbrage :
des actes soumis au timbre de dimension ;
des lettres de voiture ;
des quittances ;
des effets de commerce.
