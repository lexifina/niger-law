# Article 42

Le précompte peut être imputé par les entreprises, personnes physiques ou morales, imposées selon le régime réel d’imposition sur le montant de l’impôt sur les bénéfices. Il peut être imputé sur les acomptes et sur le solde de l’impôt sur les bénéfices ou de l’impôt minimum forfaitaire.
Après imputation du précompte sur les impôts dus, le crédit est reportable sans limitation sur les exercices suivants.
Le précompte constitue un minimum d’imposition pour les entreprises non soumises au régime réel d’imposition.
