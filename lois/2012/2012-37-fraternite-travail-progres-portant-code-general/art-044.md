# Article 44

Pour les retenues effectuées suite aux opérations faites par les entreprises privées relevant du régime réel d’imposition, bénéficiaires de prestations ou importateurs, producteurs et revendeurs en gros ou demi gros, les établissements publics, les collectivités territoriales, les projets ou ONG, les modalités de recouvrement sont celles prévues à l’article 1054 du Code Général des Impôts.
