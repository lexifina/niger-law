# Article 441

Lorsque les héritiers ou légataires universels sont grevés de legs particulier et sommes d'argent non existant dans la succession et qu'ils ont acquitté le droit sur l'intégralité des biens de cette même succession, le même droit n'est pas dû pour ce legs ; conséquemment, les droits déjà payés par les légataires particuliers s'imputent sur ceux dus par les héritiers ou légataires universels.
