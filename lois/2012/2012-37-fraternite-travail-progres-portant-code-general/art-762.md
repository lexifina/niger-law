# Article 762

Sont immeubles par l’objet auquel ils s’appliquent :
1) les droits réels immobiliers suivants :
la propriété des biens immeubles ;
l’usufruit des mêmes biens ;
les droits d’usage et d’habitation ;
l’emphytéose ;
le droit de superficie ;
les servitudes et services fonciers ;
l’antichrèse ;
les privilèges et hypothèques ;
2) les actions qui tendent à revendiquer ces mêmes droits réels.
