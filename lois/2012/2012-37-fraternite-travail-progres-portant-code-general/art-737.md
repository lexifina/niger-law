# Article 737

Les droits coutumiers exercés collectivement ou individuellement sur les terres non appropriées selon les règles du Code civil ou du régime de l’immatriculation sont confirmés au Niger.
Nul individu, nulle collectivité ne peut être contraint de céder ces droits si ce n’est pour cause d’utilité publique et moyennant une juste et préalable compensation.
Nul ne peut en faire un usage prohibé par les lois et les règlements.
