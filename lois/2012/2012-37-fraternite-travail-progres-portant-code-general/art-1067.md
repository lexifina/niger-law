# Article 1067

L’impôt exigible sur les intérêts des créances constatées par acte notarié passé au Niger est perçu :
par les notaires chargés de payer ou de percevoir ces intérêts ;
par le débiteur, lorsqu’il paie directement ces intérêts au créancier sans intervention d’un notaire.
Le versement de l’impôt perçu par les notaires est effectué dans les quinze (15) premiers jours du mois suivant. Les débiteurs des créances qui ne passent pas par l’intermédiaire d’un notaire retiennent l’impôt lors du paiement des intérêts et le reversent dans les quinze (15) premiers jours du mois suivant. Le montant de l’impôt est avancé, sauf recours, par les entreprises qui réalisent la distribution.
