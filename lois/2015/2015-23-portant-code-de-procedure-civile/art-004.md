# Article 4

Les parties peuvent se défendre elles-mêmes, sous réserve des cas dans lesquels la représentation est obligatoire.
REPUBLIQUE DU NIGER -------------------------- Fraternité –Travail – Progrès LOI N° 2015-23 du 23 avril 2015 portant Code de Procédure Civile.
Elles peuvent se faire représenter ou se faire assister par toute personne de leur choix suivant ce que la loi permet ou ordonne.
