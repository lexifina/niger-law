# Article 373

Si, sans motif légitime, le demandeur ne comparaît pas, le défendeur peut requérir jugement sur le fond qui sera contradictoire.
Le juge peut aussi renvoyer l’affaire à une audience ultérieure ou déclarer d’office l’assignation caduque. La déclaration de caducité peut être rapportée si le demandeur fait connaître au greffe dans un délai de quinze (15) jours le motif légitime qu’il n’aurait pas été en mesure d’invoquer en temps utile. Dans ce cas les parties sont convoquées à une audience ultérieure.
Aucune affaire ne peut faire l’objet de plus d’un renvoi.
