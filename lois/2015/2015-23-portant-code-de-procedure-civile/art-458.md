# Article 458

Si une partie n’exécute pas dans les délais impartis les formalités que le juge a enjoint d’accomplir et les mesures ordonnées, la partie adverse pourra obtenir l’ordonnance de renvoi prévue à l’article précédent. Le tribunal statue sur le fond par jugement contradictoire.
