# Article 318
Est qualifié escalade, toute entrée dans les maisons, bâtiments, cours, basses-cours, édifices quelconques, jardins, parcs ou enclos, exécutée par dessus les murs, portes, toitures, ou toute autre clôture.
L'entrée par une couverture souterraine autre que celle qui a été établie pour servir d'entrée est une circonstance de même gravité que l'escalade.
