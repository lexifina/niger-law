# Article 371
Dans le cas prévu à l'article précédent, le tribunal ordonnera que le jugement de condamnation soit publié intégralement ou par extraits dans les journaux qu'il désignera et affiché dans les lieux qu'il indiquera.
Le tribunal fixera le temps pendant lequel cet affichage devra être maintenu sans que la durée en puisse excéder quinze jours.
