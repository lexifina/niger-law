# Article 234

Les impôts et taxes propres à la région sont constitués de :
1. taxes rémunératoires pour services rendus conformément aux taux applicables dans la commune ;
2. taxe sur la délivrance du permis de conduire ;
3. taxe sur les zoos privés ;
4. taxe sur les concessions de chasse.
