# Article 123

- Le Comité National du Code Rural est un service public chargé de l'élaboration, de la vulgarisation et du suivi de l'application du Code Rural. Il est aidé en cela par des Secrétaires permanents créés dans les différents départements, arrondissements et communes.
Le Comité National du Code Rural est placé sous l'autorité du Ministre de l'Agriculture et de l'Elevage.
