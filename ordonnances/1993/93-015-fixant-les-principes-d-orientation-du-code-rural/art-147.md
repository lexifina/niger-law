# Article 147

- Les caisses de crédit agricole mutuel et d'épargne constituent des sociétés dont les principaux actionnaires sont :
- les organismes ruraux à caractère coopératif et mutualiste ;
- les groupements spécifiques de femmes rurales ;
- les groupements spécifiques de jeunes producteurs ruraux ;
- les associations, sociétés et établissements à vocation d'intérêt agricole ;
- les sociétés d'économie mixte constituées avec les participations des collectivités publiques locales.
