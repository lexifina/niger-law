# Article 124

- Le Secrétaire permanent départemental du Code Rural est le service technique spécialisé dans la gestion des ressources rurales du département.
Il a pour fonction l'élaboration, à l'échelon départemental, du Schéma d'Aménagement Foncier, institué par l'article 127 ci-dessous.
Le Secrétariat permanent départemental du Code Rural est placé sous l'autorité du Préfet.
