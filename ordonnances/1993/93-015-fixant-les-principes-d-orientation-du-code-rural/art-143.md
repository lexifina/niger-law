# Article 143

- Les groupements ruraux concernés sont :
- les organismes ruraux à caractère coopératif et mutualiste d’agriculteurs, d’éleveurs ou d’artisans ;
- les groupements ruraux d'intérêt économique autres que ceux-ci dessus indiqués ;
- les organismes non gouvernementaux d'intervention en milieu rural ;
- les groupements spécifiques de femmes rurales ;
- les groupements spécifiques de jeunes opérateurs ruraux
