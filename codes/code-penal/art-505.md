# Article 505

Dans le cas prévu à l’article précédent, le tribunal peut ordonner que le jugement de condamnation soit publié intégralement ou par extraits dans les journaux qu'il désigne et affiche dans les lieux qu'il indique.
Le tribunal fixe le temps pendant lequel cet affichage doit être maintenu sans que la durée en puisse excéder quinze (15) jours.
