# Code pénal (ordonnance n° 2026-09 du 16 février 2026 portant institution du Code pénal)

- Version actuelle : le Code pénal institué par l’ordonnance n° 2026-09 du 16 février 2026, signée à Niamey ; l’article 609 abroge toutes dispositions antérieures contraires ; l’article 610 prévoit sa publication au Journal officiel. Date retenue : celle de l’ordonnance (16 février 2026) ; le numéro et le jour du Journal officiel ne sont pas établis par la source (la presse fait état d’une parution consultée le 11 juin 2026).
- Source : copie gouvernementale de l’ordonnance (PDF natif, « pour ampliation » du Secrétaire général du Gouvernement), publiée par la base de données de l’ILGA World, <https://database.ilga.org/api/downloader/download/1/NE%20-%20LEG%20-%20Penal%20Code%20(2026)%20-%20OR%20(fr).pdf> (copie secondaire ; aucune OCR).
- Version précédente (historique git) : le Code pénal de 1961 (loi n° 61-27 du 15 juillet 1961) dans l’édition refondue du Ministère de la Justice de janvier 2018.
- Fichiers : `visas.md`, `art-001.md` à `art-610.md` (610 articles), `signatures.md` ; les intitulés des livres, titres, chapitres et sections sont omis. L’article 382 est imprimé « Article 82 » dans la source (coquille, entre les articles 381 et 383).
